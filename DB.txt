[데이터베이스] : 여러 사람이나 여러 프로그램이 공유해 사용할 수 있도록 데이터 집합
    - 데이터베이스 서버 : MYSQL , 요청에 따라 데이터 처리하고 응답하는 프로그램
    - 특징 : 실시간접근, 동시공유, 데이터참조, 지속적인 변화 등
    - 종류 : 1) 관계형데이터베이스(SQL) 2) NOSQL

[SQL] : 관계형데이터베이스 데이터를 조작/제어 하기 위한 표준어
    1) DDL 데이터 정의 어   : 데이터베이스/테이블 정의하고 변경
    1) DML 데이터 조작 어   : 테이블내 데이터들을 조작
    1) DCL 데이터 제어 어   : 데이터베이스 접근권한 / 계정관리
    1) TCL 트렌젝션 제어  어   : DML 실행 결과물 취소/적용

[메타데이터]
    SHOW DATABASE;
    USE DB명
    DESCRIBE 테이블명;

[DDL]
    DROP:
        DROP DATABASE IF EXISTS DB명;
        DROP TABLE 테이블명;
    CREATE:
        CREATE DATABASE DB명;
        CREATE TABLE 테이블명(필드명 타입 제약조건);
    ALTER:
        ALTER TABLE 테이블명 ADD 필드명 타입;
        ALTER TABLE 테이블명 MODIFY 필드명 새로운타입;
        ALTER TABLE 테이블명 CHANGE 기존필드명 새로운필드명 새로운타입;
    RENAME:
        RENAME TABLE 테이블명 TO 새로운테이블명;
    TRUNCATE:
        TRUNCATE TABLE 초기화테이블명;

[타입]
    정수 : TINYINT, SMALLINT, MEDIUMINT, *INT*, BIGINT
        * UNSIGNED : 부호가 없는 자료, -128~127 -> 0~255
    실수 : FLOAT, DOUBLE, DECIMAL(문자열실수)
    날짜 : DATE, 시간: TIME, 날짜/시간: *DATETIME*
    문자열 : CHAR(N), *VARCHAR(N)*, TEXT, LONGTEXT
        * CHAR(3) : 고정의 3글자, [사][과][]
        * VARCHAR(3) : 가변의 3글자, [사][과]
        * LONGTEXT : 대용량
    논리 : BOOLEAN(TINYINT)

[제약조건] 
    1. NOT NULL                 : 값이 NULL이면 레코드 등록 불가
    2. UNIQUE                   : 값이 중복이면 레코드 등록 불가
    3. DEFAULT 기본값           : 레코드 등록시 값 생략하면 기본값 대입
    4. AUTO_INCREMENT , *PK인 경우만 사용가능* : 레코드 등록시 자동 증가 번호 대입
    5. CONSTRAINT PRIMARY KEY(PK필드명) : 기본키/식별키
    6. CONSTRAINT FOREIGN KEY(FK필드명) REFERENCE 참조테이블명(PK필드명)    : 외래키/참조키

[참조옵션]
    1. ON DELETE/UPDATE CASCADE : PK가 삭제되면 FK 레코드도 같이 삭제
    2. ON DELETE/UPDATE RESTRICT : (생략시기본값) PK가 참조중이면 삭제 불가능
    3. ON DELETE/UPDATE SET NULL : PK가 삭제되면 FK 값은 NULL

[DML]
    1. INSERT INTO 테이블명(필드명, 필드명)VALUES(값1,값2);
        - INSERT INTO 테이블명 VALUES(값1,값2,값3);         : 모든 필드의 값 대입시 필드명 생략가능
        - INSERT INTO 테이블명(필드명) VALUES(값),(값);     : 2개 이상 레코드 등록시 
    2. SELECT 필드명 FROM 테이블명 WHERE 조건
        - SELECT * FROM 테이블명 : 테이블내 모든 필드의 레코드 조회
    3. UPDATE 테이블명 SET 필드명 = 수정할값 , 필드명 = 수정할값 WHERE 조건
    4. DELETE FROM 테이블명 WHERE 조건

[연산자]
    1. AS :  별칭, 필드명 AS 별칭 , 테이블명 AS 별칭 , *주의할점: 생략가능
    2. DISTINCT : 조회결과 (필드값) 중복제거
    3. 산술연산자 : + - / * DIV(몫) MOD(나머지)
    4. 비교연산자 : = != > < >= <=
    5. 논리연산자 : AND이면서 OR이거나 NOT부정
        *BETWEEN 시작값 AND 끝값 , * IN(값1,값2,값3)
    6. NULL연산자 : 
        필드명 = NULL       <불가능>
        필드명 IS NULL      <가능> 
        필드명 IS NOT NULL  <가능>  
    7. 문자열패턴 : 필드명 LIKE "문자열패턴"
        % : 모든 문자 대응              , 김% : 김으로 시작하는 N글자 조회
        _ : 언더바 개수만큼 문자 대응   ,  김_ : 김으로 시작하는 2글자 조회
